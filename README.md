# Atelier Aurelia — Company Profile

An interactive, page-turning digital company profile (brochure) for Atelier Aurelia,
an interior design & turnkey fit-out studio.

- Single-page static site: `index.html` + `assets/` images. No build step, no dependencies to install.
- Features: 3D page-turn navigation, a WebGL cover motif (three.js via CDN), a filtered project
  portfolio, team directory, and click-to-edit inline text (edits save in the viewer's own browser).

## View locally
Open `index.html` in any modern browser.

## Hosted
Published with GitHub Pages — see the repository's **Pages** URL.
